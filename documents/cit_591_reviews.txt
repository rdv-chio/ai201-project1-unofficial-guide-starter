"A Good Primer to Introductory Programming, but With Some Flaws"

Overall Course Rating: 7/10

TL;DR (Detailed review below):

• CIT 591 is a good introduction to programming and object-oriented design in both Python and Java
• Some people struggle at the halfway mark, when the course transitions from Python to Java
• Lectures are decent, they could definitely be improved upon as they tend to be a bit too basic, the organization is a bit all over the place at times, and concepts only pick up pace as the semester goes on
• Grading structure of the class is fair. Most of the grade is based on homework assignments
• Homeworks tend to be much more complicated and challenging than anything presented in the lectures, leading to a rather unexpected (and sometimes harsh) spike in difficulty
• Quizzes, Midterm Exam, and Final Exam are extremely fair
• A large portion of students do end with an A in the class
• Good for developing software development fundamentals, although I wish they talked a bit more about working with data
• TA's are extremely responsive, office hours are useful and helpful:

My detailed thoughts on the course:

CIT 591 is the first course you take in the MCIT Program. It is roughly equivalent to an introductory programming/object-oriented programming class which one would normally take within the first year of an undergraduate computer science degree program. This class is supposed to serve as an introduction to the fundamentals of programming and was designed for students with minimal to no experience in programming in any language. That being said, I did have quite a bit of experience programming in Python previously, so it definitely gave me an advantage while heading into the course.

The course starts off with basic concepts such as variables, flow control, loops, data types, functions, unit testing, and file I/O. Later on, the course delves further into object-oriented concepts such as class-based structure, polymorphism, inheritance, abstract classes, and more. Unlike most introductory programming classes at other universities, which are primarily taught in one language, the first half of CIT 591 is taught in Python, and the second half of the course is taught in Java. The logic behind this is that Python is more beginner-friendly in terms of syntax and logic, so learning how to code in Python is a great way to start learning how to think like a programmer. Once the course delves into more objected-oriented programming concepts, the rest of the course is taught in Java. I do think this is a cool idea because it gives students exposure and practice in two programming languages. However, I'm inclined to believe that the traditional approach of teaching students one language would be better (In fact, the MCIT on-campus version of CIT 591 is taught exclusively in Java). Lots of students, especially those who had no experience programming before, tended to struggle after the midterm when the course switched from Python to Java. This was primarily due to the drastic change in syntax and code structure which had to be taught and adjusted to in a very short amount of time.

The lectures in this class were decent in my opinion. They're essentially the exact same lecture videos as the Coursera MOOC course that Penn hosts. I do think they teach the necessary concepts, and they do a pretty good job at that, which is great. However, I have two main grievances with the lectures. First, some of the modules have way too many lecture videos which hurts the organization of the topics. There are many lecture "videos" which are only 15-20 seconds long, which is annoying to sift through. Second, the course suffers from an issue that a lot of other intro programming classes have. Simply teaching the fundamental concepts and providing basic examples and use cases does not adequately translate to using those concepts to build a more complicated program, which one would have to do in the homework assignments. There are some code-along videos as well as practice assignments which can help students with solidifying concepts, but considering the workload one has per week, it's not really realistic to do the practice assignments (I don't know anyone who did any practice assignments to be completely honest). I do suggest actively asking TA's and using sites such as GeeksforGeeks or Stack Overflow when it comes to better understanding concepts. The lecture videos are simply too basic in my opinion, and the homework assignments would require a more sophisticated or complicated use of the concepts taught in class.

The grading structure in this class is quite fair. 65% of the grade is split across 8 different homework assignments. These assignments typically encompass some kind of programming project which uses concepts taught in the lectures for the module. The first 3 homeworks were due each week, and the last 5 were due on a biweekly basis. 5% of the grade is based on module quizzes. These are small quizzes held on Canvas which test the concepts in each module. There are 2 quizzes per module/week, and each quiz has unlimited attempts, so there is no reason you shouldn't get a perfect score in quizzes. 15% of the grade is based on a take home midterm which was done in Python, and the Final exam was split into two parts, a take home part which was 10.5% of the grade, and a written, proctored exam which was 4.5% of the grade.

A big complaint I have with the course evaluation is the homework assignments. Many students in the class found the homework assignments to be quite daunting. This is due to the fact that the homework assignments are quite lengthy, and there is a much bigger spike in difficulty in the homework compared to the lecture content. While the lectures go over basic examples/use cases of different concepts, the homeworks require much more sophisticated use and implementation of the same concepts, even more complex than anything shown in the code-along videos. The course pace only increases over time, and the difficulty of material only gets harder. Some people were falling behind and struggling on homeworks as early as assignment 3, which was due after the third week of classes. Some of the early assignments are also auto-graded with a very specific testing implementation, so your program may work as normal, but can still fail the autograder which is annoying. I personally found the assignments to be manageable in terms of difficulty (thanks to prior programming experience), but they were still quite time consuming. While I worked about 8 hours per week on average in the course (time spent watching lectures, taking quizzes, doing homework each week), people who tend to struggle more with programming or those who have less experience in programming might spend closer to 15-20 hours a week.

The quizzes, midterm exam, and final exam, however, are very fair. Quizzes have unlimited attempts and are fairly simple. The Python midterm exam was a pretty easy take home assignment similar to the homeworks (but much easier because there are only 5 days to complete it). The final Java take home exam was also a fairly simple assignment, easier than much of the previous homework assignments done in Java. The written portion of the final exam (which is proctored via HonorLock), is a bit challenging, but it is worth such a small portion of the grade (only 4.5% of the final grade). Many people do so well in all the other assignments in the class that they could get a 0% on the written portion of the final, and still end with an A. I will also admit that the final week of classes was certainly a struggle as we had 25% worth of our grade due within one week after finishing Thanksgiving break (HW 8 and the Java Final Exam).

As a final personal gripe, I do find the content in this class to be a bit boring. This is kind of a crazy thing to say as a student entering a computer science program, but I've already seen much of this content before. Furthermore, the content in this class is definitely more geared for solid fundamentals in software development before heading into more complex topics such as data structures. However, as someone who is more interested in a future career as a data scientist or researcher (who primarily works with Python and data science methods), I'm just not as interested in programming in Java and working on assignments where we have to "build" programs, or work heavily with object-oriented design. I would have much preferred smaller assignments which contain multiple short, yet immersive tasks rather than one large all-encompassing program. There are two optional modules in the class, one on version control using Git and databases using SQL, and the other on data analysis using pandas, numpy, and matplotlib. It's unfortunate that these modules are only optional considering they're both extremely useful and practical modules which you would actually need to use at a job (especially for data analysis and data science jobs where numpy, pandas, jupyter, and SQL are widely used). However, this is just a small gripe and does not heavily impact my actual thoughts regarding the course.

I never went to office hours much, nor did I use the discussion boards beyond logistical questions, but I have found that the TA's are extremely responsive to student inquiries, and TA office hours and instructor office hours have been very helpful and are super approachable. TA's also held some unique office hours covering data analysis, Git, and Linux/Unix as well. Definitely some of the best TA and instructor support I've ever seen, especially for such a large class. Definitely take advantage of these resources if you struggle with certain topics in the class.

Overall, I think CIT 591 is a good introduction to programming. It still suffers from the problems a lot of other intro programming classes have (mainly assignments being time consuming & tougher than lectures, and some less than favorable pacing for newcomers to programming), but the fundamentals are still well taught, and the TA's and course staff definitely make the experience much more welcoming and easier. Plenty of students do well, regardless of their prior experience, so if you put in the effort to practice and learn, you'll do great.

TL;DR:
This class is fantastic! It covers many immediately-useful concepts to propel a complete beginner to a functional programmer. If you already have programming experience, it's an easy class.

The first half covered Python, but in a way that's suitable for absolute beginners. After the basics, we covered important topics like file import/export and data parsing. I was already familiar with coding, so the Python module was a breeze. Python midterm was an open-book take-home exam.

The second half covers Java. In my case, I already had experience with object-oriented programming (OOP) through C++, so I had minimal difficulty with the concept of OOP and Java syntax. However, for a beginner, it can be quite a left turn and the course covers a lot of material, fast. The focus was on teaching functionally useful concepts, such as Collections and RegEx. Final exam was not easy, but partly because we had to use VSCode through Codio, which was clunky to say the least.

My advice to anyone taking this course:
Do ALL the assignments even if they're optional and don't explicitly count towards your grade - they helped me hone my programmatic thinking and become comfortable with syntax and useful object methods.
